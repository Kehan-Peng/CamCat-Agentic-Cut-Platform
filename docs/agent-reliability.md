# Agent 与工作区可靠性

## 执行与恢复

浏览器的 SSE 连接与 Agent 执行分离。每个 API 进程最多并行执行 4 个 Agent，运行与排队合计最多 8 个；超过容量返回 503。断开浏览器连接不会取消已经接收的剪辑任务。

每个完成节点都提交到 PostgreSQL，SSE 空闲期间每 10 秒发送心跳。事件回放使用与实时流相同的节点序号，前端仍以 Graph Run 查询和已持久化版本作为恢复依据。

此机制支持网络断线，不支持 API 进程重启后的任务续跑。进程级恢复、跨实例调度与任务取消需要后续迁移到持久化任务队列；不能把当前机制视为完整的灾难恢复方案。

## 计划质量

计划节点接收用户原始要求和当前时间线。所有计划先检查非空片段、真实候选 ID、有限数值和来源时间边界。无效结果连同错误原因交给真实模型纠正一次，再次失败则终止；不会凭空添加素材或写入无效版本。

模型返回非 JSON 时也允许一次有界的格式纠正请求。传输层的超时和重试策略不变。模型只能返回类型化 Domain Command；时间码使用整数微秒，内部审计 patch 由 reducer 确定性生成。

## 用户操作

- 草稿按用户、项目和会话隔离，保存在当前浏览器标签页的 sessionStorage；失败不会清空输入。
- 中文输入法候选确认不会触发提交，空输入和任务执行中不能重复发送。
- 首次请求失败后保留已创建的会话，重试不会重复建会话。
- 409 保留状态码、版本详情和请求 ID；“刷新剪辑版本”加载最新状态并保留输入，让用户确认后再发送。
- Job 查询对断网、429、502/503/504 最多尝试三次，不自动重发写操作。
- 语音输入错误显示在提示区域，不污染剪辑需求。

## 验证

`make test` 检查静态类型、契约、单元测试和 Web 构建。`make test-integration` 使用真实 PostgreSQL、Milvus、MinIO、FFmpeg，并在独立数据库验证迁移。

`tests/integration/test_external_qwen.py` 验证真实模型和浏览器断线后的剪辑完成；容器中 API 默认地址为 `http://api:8000`，宿主机运行时设置 `CAMCAT_TEST_API_URL=http://localhost:8000`。

Playwright 包含草稿/输入法恢复、原有布局走查，以及上传、计划、渲染播放、多轮修改、回滚、409 和版本刷新。完整流程仍需配置真实媒体及可用的公网 HTTPS 媒体地址。临时隧道仅适合本地验证，长期使用需稳定域名和反向代理。
